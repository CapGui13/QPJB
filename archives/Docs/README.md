## Fichiers conservés ici volontairement

Les fichiers `.json` et `.csv` du dossier `Docs/` restent **aux chemins d'origine** : certains scripts de contrôle et workflows les lisent directement. L'aperçu HTML V2 reste également à son emplacement pour préserver ses éventuels liens directs. Les sept images pédagogiques ne sont pas déplacées.

Les rapports archivés ont été déplacés avec leurs contenus conservés ; les liens Markdown relatifs vers `audits/` ont été ajustés lorsque nécessaire. Cette réorganisation ne change ni les QCM, ni le moteur V1, ni les sauvegardes.
